# Amazon Reviews NLP Analysis

A data pipeline that scrapes, cleans, and analyzes Amazon product reviews
from a Black Friday campaign using NLP techniques. (NTI program, grade B+)

## Overview
- **Role:** Full pipeline — scraping, preprocessing, feature engineering
- **Status:** Completed
- **Tech:** Python, web scraping, NLP

## What it does
1. **Scraping:** collects product title, price, discount, rating, and
   description from the Amazon Black Friday campaign
2. **Review collection:** scrapes reviews for every product with at least
   one rating, indexed against the products dataset
3. **Preprocessing:** cleans the review text and engineers new features
   from the description column

## Skills applied
Python, web scraping, NLP, data cleaning, feature engineering.
